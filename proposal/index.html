01

인트로RFP를 관통하는 미션 정립

  • 제안서 전체를 하나로 묶는 미션 스테이트먼트 1문장을 정의하는 단계입니다.
  • 이후 모든 장표는 이 미션을 달성하기 위한 근거로 쓰여야 합니다.

작성 방법

  1. RFP에서 광고주가 명시한 목표와 KPI 수치를 그대로 뽑습니다.
  2. RFP 행간에 숨은 진짜 고민을 한 줄로 정리합니다.
  3. 둘을 합쳐 "[누구에게] [무엇으로] [어떤 성과를] 만든다" 형식의 미션 1문장을 씁니다.
  4. North Star KPI 1개와 보조 KPI 2~3개를 정합니다.

장표 구성 · 2~3p

  • RFP 요약: 목표 · 예산 · 기간 · KPI.
  • 우리가 읽은 과제: 표면 목표와 핵심 과제 대비.
  • 미션 스테이트먼트와 KPI 트리.

체크포인트

  • 미션 문장에 KPI 수치와 기한이 들어갔는가?
  • 아웃트로에서 다시 불러올 수 있는 문장인가?
  • 광고주가 RFP에 쓴 용어를 그대로 사용했는가?
02

타겟 어프로치RFP·팩트북 기반 타겟 설정

  • 미션을 달성하려면 누구를 움직여야 하는지 데이터로 정의하는 단계입니다.
  • 인구통계뿐 아니라 구매 동기, 검색 행동, 구매 장벽까지 담아야 03 VP로 이어집니다.

작성 방법

  1. RFP의 타겟 정의와 팩트북(구매자 데이터, CRM, 제품 정보)을 교차 확인합니다.
  2. 검색 데이터(네이버 데이터랩 등), 소셜 리스닝, 리뷰로 니즈와 불만을 뽑습니다.
  3. 코어 타겟과 확장 타겟으로 나누고, 각각 페르소나 1명씩 정의합니다.
  4. 타겟별 구매 여정의 주요 터치포인트를 표시합니다.

장표 구성 · 3~4p

  • 데이터 인사이트: 검색량 추이, 연관 키워드, 리뷰 키워드를 장표 1개에 하나씩.
  • 타겟 정의: 코어/확장 조건과 규모 추정.
  • 페르소나와 구매 여정 맵.

체크포인트

  • 모든 인사이트에 데이터 출처와 조회 기간이 표기되었는가?
  • 타겟 조건이 실제 매체 타겟팅(관심사, 키워드, 리타겟팅)으로 구현 가능한가?
  • 매체 AI 자동 확장을 쓸 경우, 타겟 정의를 "소재 메시지 설계 기준"으로 연결했는가?
03

커뮤니케이션 어프로치타겟 기반 VP 도출 및 소재 제안

  • 타겟 니즈와 제품 강점이 만나는 지점에서 VP를 뽑고, 실제 소재로 보여주는 단계입니다.
  • 매체 AI는 소재를 배분할 뿐 만들지는 않으므로, 자동화 환경일수록 소재력이 성과 차이를 만듭니다(AMPM).

작성 방법

  1. 02의 타겟 니즈·불만과 제품 USP를 두 열로 놓고 연결되는 지점을 찾습니다.
  2. 타겟별 VP를 1문장으로 정리하고 소구점(기능·감성·혜택·사회적 증거)을 나눕니다.
  3. 소재 트랙을 2~3개로 구성하고 트랙별 카피·비주얼 시안을 만듭니다.
  4. 소재마다 활용 퍼널과 포맷(숏폼, 이미지, 카탈로그)을 태깅합니다.

장표 구성 · 4~6p

  • 니즈 × USP 매핑과 VP 도출 과정.
  • 소재 트랙 개요: 메시지 · 타겟 · 퍼널.
  • 실제 지면 목업 시안(메타 피드, 구글 디맨드젠, 네이버 배너 등).

체크포인트

  • VP가 타겟 인사이트 장표의 데이터에서 논리적으로 이어지는가?
  • 트랙마다 검증할 가설이 분명한가?
  • 매체 AI가 조합할 수 있도록 소구점이 다양한 소재 묶음으로 제안되었는가?
04

매체 전략타겟·소재 기반 퍼널 전략

  • 타겟을 어디서 만나고, 어떤 소재를 어떤 퍼널 단계에 태울지 정하는 단계입니다.
  • 매체를 나열하지 않고 퍼널 단계별 역할로 설명해야 07 예산 배분의 근거가 됩니다.

작성 방법

  1. 퍼널을 인지 → 고려 → 전환 → 리텐션 4단계로 나눕니다.
  2. 단계별로 02의 터치포인트에 맞는 매체·상품을 배치합니다.
  3. 단계별 핵심 KPI를 지정합니다.
  4. 03의 소재 트랙을 단계별 매체에 매핑합니다.

장표 구성 · 2~3p

  • 퍼널 맵: 단계 × 매체 × 소재 × KPI 한 장 요약.
  • 매체 선정 근거: 타겟 도달 규모, 업종 벤치마크, 과거 성과.

체크포인트

  • 매체별 역할이 겹치지 않는가(Advantage+는 수요 창출, PMax는 높은 의도 포착 등)?
  • 검색 중심에 머물지 않고 디맨드젠·숏폼 같은 수요 창출 단계를 포함했는가(AMPM)?
  • 소액 예산이라면 매체를 2~3개로 집중했는가?
05

운영 플랜퍼널별 매체 운영 제안

  • 04의 퍼널 맵을 실제 계정 세팅 수준으로 내리는 단계입니다.
  • 광고주가 "다음 주부터 바로 돌릴 수 있겠다"고 느낄 만큼 구체적이어야 합니다.

작성 방법

  1. 매체별 캠페인 구조(캠페인 → 광고그룹 → 소재)를 도식화합니다.
  2. 타겟팅 옵션, 입찰 전략(타겟 CPA/ROAS, 수동 CPC 등), 학습 기간 예산을 명시합니다.
  3. 런칭 후 주차별 운영 로드맵을 작성합니다.
  4. 런칭 전 준비사항과 소요 기간을 정리합니다.

장표 구성 · 매체당 1~2p

  • 매체별 캠페인 구조도와 세팅표.
  • 주차별 운영 로드맵과 런칭 전 준비 일정.

체크포인트

  • 계정 구조를 지나치게 쪼개지 않았는가(2026년 권장 원칙은 "더 적게, 더 크게", 메타 캠페인 2~3개 — 디지털마케터)?
  • 학습 기간 동안 성과가 낮을 수 있다는 점을 미리 알렸는가?
  • 런칭 일정이 광고주 소재 제공·개발 일정과 맞는가?
06

최적화소재 및 운영 최적화 방식

  • "어떤 기준으로, 얼마나 자주, 무엇을 바꿀지"를 룰로 보여주는 단계입니다.
  • 자동화 매체 비중이 커질수록 입찰 조정보다 소재 테스트와 시그널(전환 데이터) 품질 관리가 핵심입니다.

작성 방법

  1. 03의 트랙별 가설을 A/B 테스트 설계로 바꾸고 판단 기준을 정합니다.
  2. 빈도·CTR 하락 기준으로 소재 교체 주기를 제안합니다.
  3. 예산 재배분, 타겟 확장·축소, 키워드 정리를 If → Then 룰로 정리합니다.
  4. 주간·월간 최적화 사이클을 정하고 09 리포트 체계와 연결합니다.

장표 구성 · 2~3p

  • 소재 테스트 로드맵: 변수 · 기간 · 판단 기준.
  • 운영 최적화 룰표.
  • 최적화 사이클(일/주/월).

체크포인트

  • 판단 기준에 최소 표본(노출·전환 수)이 포함되었는가?
  • 자동화 캠페인에서 마케터가 통제할 수 있는 영역(소재, 피드, 전환 가치, 제외 타겟)을 명시했는가?
  • 학습 기간을 해치는 잦은 변경을 막는 규칙이 있는가?
07

포캐스팅미디어믹스

  • 01에서 정한 KPI를 달성할 수 있는지가 이 장표에서 검증됩니다.

작성 방법

  1. 매체별 단가 가정을 업종 벤치마크와 자사 운영 데이터로 설정합니다.
  2. 퍼널 역할에 따라 예산 비중을 배분합니다.
  3. 세 시나리오로 예산과 예상 성과를 나눕니다.
  4. 학습기 효율 하락을 포함한 월별 성과 흐름을 표시합니다.

체크포인트

  • 모든 단가 가정에 출처 또는 "자사 데이터 기반 추정"이 표기되었는가?
  • 예상 성과를 단일 값이 아닌 범위로 제시하고 전제 조건을 밝혔는가?
  • 08 트래킹이 미비하면 측정 성과가 실제보다 낮게 잡힐 수 있다는 점을 연결했는가?
08

기술 트래킹GA/GTM 등 트래킹 점검

  • 광고주의 현재 측정 환경을 진단하고, 성과를 정확히 재기 위한 개선안을 제시하는 단계입니다.
  • 2026년에는 메타 전환 API(CAPI)가 사실상 기본 요건이 되었고, 픽셀만 쓰면 iOS 제한·동의 배너·광고 차단기 때문에 전환이 누락됩니다(WeTracked).
  • 자동 입찰은 전환 데이터로 학습하므로, 트래킹 품질이 곧 운영 성과로 이어집니다.

작성 방법

  1. 사이트·앱의 태그 현황(GA4, GTM, 매체 픽셀, MMP)을 점검합니다.
  2. 핵심 전환 이벤트 수집 여부와 매체·GA4·실제 매출 간 차이를 비교합니다.
  3. 문제를 긴급/권장/선택으로 나눠 진단표를 만듭니다.
  4. 개선 로드맵(서버 GTM, CAPI, 향상된 전환, 동의 모드)을 단계별로 제안합니다.

체크포인트

  • 픽셀과 CAPI를 함께 쓸 때 중복 제거 설계를 포함했는가?
  • 광고주 개발 리소스가 필요한 작업과 대행사 단독 작업을 나눠 표기했는가?
  • 사이트 접근이 어려우면 "수주 후 2주 내 정밀 진단" 같은 실행 계획으로 대체했는가?
09

리포트 · 업무 프로세스레버 엑스퍼트, 미팅 프로세스 정립

  • 수주 이후 어떻게 함께 일하는지 구체적으로 보여주어 운영 안정성에 대한 신뢰를 주는 단계입니다.
  • 레버 엑스퍼트 등 사내 리포트 솔루션으로 데이터 투명성과 보고 자동화를 강조합니다.

작성 방법

  1. 리포트 체계를 일간·주간·월간·분기로 나눕니다.
  2. 레버 엑스퍼트의 대시보드 화면과 제공 지표를 캡처로 보여줍니다.
  3. 미팅 프로세스(킥오프 → 주간 → 월간 → QBR)와 안건을 정합니다.
  4. 담당 조직도와 R&R, 이슈 대응 SLA(예: 긴급 이슈 2시간 내 회신)를 제시합니다.

체크포인트

  • RFP가 요구한 리포트 주기·형식을 모두 충족하는가?
  • 담당자 실명·직급·경력이 들어간 조직도인가?
  • 레버 엑스퍼트 화면이 최신 버전 캡처인가?
10

서비스수수료 및 제작비 관련 어필

  • 거래 조건을 명확히 제시해 가격 경쟁력과 투명성을 보여주는 단계입니다.
  • 단순 할인보다 "이 조건으로 얻는 가치"를 함께 보여주는 것이 핵심입니다.

작성 방법

  1. 매체별 대행 수수료 구조(매체 수수료, 별도 운영료 여부)를 표로 정리합니다.
  2. 소재 제작 범위(월 제작 수량, 포맷, 수정 횟수)와 비용 조건을 명시합니다.
  3. 무상 부가 서비스를 묶어 서비스 패키지로 보여줍니다.
  4. 예산 규모별 티어를 제시합니다.

체크포인트

  • 제안 조건이 사내 영업·재무 담당자 승인을 받았는가?
  • RFP의 가격 평가 항목·양식에 맞춰 작성했는가?
  • 무상 제공 항목의 범위와 기간이 모호하지 않은가?
11

어팬딕스베스트 레퍼런스 / 별도 솔루션 어필

  • "실제로 해낸 적이 있다"는 근거와, 본문에 다 담지 못한 추가 역량을 보여주는 단계입니다.
  • 본문 흐름을 끊지 않도록 상세 자료는 이곳에 모읍니다.

작성 방법

  1. 광고주와 업종·과제가 가장 비슷한 레퍼런스 2~3건을 고릅니다.
  2. 과제 → 전략 → 실행 → 성과(전후 수치) 구조로 씁니다.
  3. 자체 솔루션(레버 엑스퍼트, 내부 데이터·AI 툴)을 "이 광고주의 어떤 과제를 푸는지" 기준으로 소개합니다.
  4. 매체 세팅 상세, 키워드 리스트, 소재 원본 등 보조 자료를 첨부합니다.

체크포인트

  • 레퍼런스 수치가 공개 가능한 범위인가(기존 광고주 동의, 비식별화)?
  • 솔루션 소개가 본문 01~08의 과제와 연결되는가?
12

아웃트로클로징 임팩트

  • 01의 미션을 다시 불러와 "왜 우리여야 하는가"를 한 번에 각인시키는 단계입니다.
  • 심사위원이 마지막으로 보는 장표이므로, 가장 기억에 남을 한 문장이 필요합니다.

작성 방법

  1. 01 미션 문장을 다시 제시합니다.
  2. 02~10의 핵심을 3~5개 키워드로 압축합니다.
  3. 런칭 후 30/60/90일 약속을 제시합니다.
  4. 클로징 카피 1문장으로 마무리합니다.

체크포인트

  • 클로징 카피가 다른 광고주에게도 쓸 수 있는 일반론이 아닌가?
  • 30/60/90일 약속이 05 운영 로드맵과 일치하는가?
  • "무조건 ROAS 2배" 같은 단정 대신 07의 범위 수치를 사용했는가?
